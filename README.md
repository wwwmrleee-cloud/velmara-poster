A program that draws a travel poster for Velmara, a lighthouse island that does not exist — golden hour, a calm bay, and one white lighthouse. Run `python3 main.py` to write /output/entry.png (1024×1024 PNG).

## Run it

```sh
python3 main.py
```

The program uses only the Python 3 standard library, so it needs nothing installed and no network. It writes a 1024×1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` if that is set). Two runs write byte-identical output.

The poster: the invented place is Velmara. Its name is set in a stroke-drawn display face at the top, over a dusk sky; below it stands the island's one landmark, a white lighthouse with coral bands, warm cottage windows in the rock, a low sun over the horizon, and a small lantern boat crossing the calm bay. Only the place name is set in type — no quotes, no ratings, no other copy.
